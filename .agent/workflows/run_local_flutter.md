---
description: Run Flutter commands using the locally installed SDK
---

To run Flutter commands, use the absolute path to the local installation:

```powershell
C:\Users\colli\.gemini\antigravity\scratch\flutter\bin\flutter.bat [command]
```

Examples:

**Run pub get:**

```powershell
C:\Users\colli\.gemini\antigravity\scratch\flutter\bin\flutter.bat pub get
```

**Run the app:**

```powershell
C:\Users\colli\.gemini\antigravity\scratch\flutter\bin\flutter.bat run
```

**Analyze code:**

```powershell
C:\Users\colli\.gemini\antigravity\scratch\flutter\bin\flutter.bat analyze
```

**Build APK:**

```powershell
C:\Users\colli\.gemini\antigravity\scratch\flutter\bin\flutter.bat build apk
```
